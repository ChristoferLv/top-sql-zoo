1. Bender goals
R: Show the matchid and player name for all goals scored by Germany. To identify German players, check for: teamid = 'GER'

>SELECT matchid, player FROM goal 
  WHERE teamid LIKE 'GER'

2. Team names
R: Show id, stadium, team1, team2 for just game 1012

>SELECT id,stadium,team1,team2
  FROM game
WHERE id = 1012

3. JOIN
r: show the player, teamid, stadium and mdate for every German goal.

>SELECT player,teamid,stadium,mdate
  FROM game JOIN goal ON (id=matchid)
WHERE teamid = 'GER'

4. Mario goals
R: Show the team1, team2 and player for every goal scored by a player called Mario player LIKE 'Mario%'

SELECT team1,team2,player
  FROM game JOIN goal ON (id=matchid)
WHERE player LIKE 'Mario%'

5. Early goals
R: Show player, teamid, coach, gtime for all goals scored in the first 10 minutes gtime<=10

>SELECT player, teamid, coach, gtime
  FROM goal 
 JOIN eteam
ON teamid=id WHERE gtime <=10

6. Fernando Santos
R: List the dates of the matches and the name of the team in which 'Fernando Santos' was the team1 coach.

>SELECT mdate, teamname
FROM game
JOIN eteam
ON game.team1 = eteam.id
WHERE coach = 'Fernando Santos'

7. Games in Warsaw
R:List the player for every goal scored in a game where the stadium was 'National Stadium, Warsaw'

>SELECT player
from goal
join game
on matchid=id
WHERE stadium LIKE 'National Stadium, Warsaw'

8. Who scored against Germany
R: show the name of all players who scored a goal against Germany.

>SELECT DISTINCT player
  FROM game JOIN goal ON matchid = id 
    WHERE (team1='GER' OR team2='GER') AND teamid != 'GER'

9. Total goals scored
R:Show teamname and the total number of goals scored.

SELECT teamname, COUNT(*)
  FROM eteam JOIN goal ON id=teamid
 GROUP BY teamname

10. Goals by stadium
R: Show the stadium and the number of goals scored in each stadium.
SELECT stadium, COUNT(*)
  FROM game JOIN goal ON id=matchid
 GROUP BY stadium

11. Poland's games
R: For every match involving 'POL', show the matchid, date and the number of goals scored.
SELECT matchid, mdate, count(*)
  FROM game JOIN goal ON matchid = id 
 WHERE (team1 = 'POL' OR team2 = 'POL')
GROUP BY matchid, mdate

12. Germany scores
R: For every match where 'GER' scored, show matchid, match date and the number of goals scored by 'GER'
SELECT matchid, mdate, count(*)
  FROM game JOIN goal ON matchid = id 
 WHERE teamid = 'GER'
GROUP BY matchid, mdate

13. All scores
R: List every match involving the ENG team, show the number goals scored by each team as shown. This will use "CASE WHEN" which has not been explained in any previous exercises.

>SELECT mdate, team1, 
SUM(CASE WHEN teamid=team1 THEN 1 ELSE 0 END), team2,
SUM(CASE WHEN teamid=team2 THEN 1 ELSE 0 END)
FROM game
LEFT JOIN goal
ON id=matchid
WHERE 'ENG' in (team1, team2)
GROUP BY mdate, team1, team2
