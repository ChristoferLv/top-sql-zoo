# SQL Zoo

This project documents the SQL exercises completed on SQLZoo.org as part of The Odin Project's Databases path: [SQL Zoo | The Odin Project](https://www.theodinproject.com/lessons/node-path-databases-sql-zoo).

## Project Objective

The main goals were to practice core SQL skills by solving a sequence of guided exercises on SQLZoo:
- Basic and advanced `SELECT` queries
- Filtering, ordering and projection
- Aggregation with `SUM`, `COUNT` and grouping
- `JOIN` operations and self-joins
- Handling `NULL` values and numeric examples
- Window functions and subqueries

## What Is It?

This folder contains copies of the exercises and the answers for the SQLZoo lessons. Unlike other projects from **The Odin Project**, this one is not a creation of an script/webpage, but the execution of a list of exercises on a external site.

## What is inside the files

- Each file contains the exercise prompt and the queries used as answers.
